# Контекст задачи и восстановление

Эти инструкции активны через `opencode.json`, а не архив Claude.
При старте и после уплотнения контекста прочитай AGENTS.md, CONCEPT.md,
README.md, DECISIONS.md, BOARD.md, BACKLOG.md и спецификацию текущей задачи.
Определи текущую ветку и HEAD через `git branch --show-current` и
`git rev-parse HEAD`; сверь задачу с Doing в BOARD.md. Если привязка неоднозначна,
верни вопрос лиду, не выбирай задачу по догадке. BOARD/BACKLOG остаются единой
проектной очередью, Ensemble отражает только её исполнение.

Прежние SessionStart `dt context --hook` и Claude statusLine больше не нужны
для получения контекста: `dt context` отсутствует в CLI 2.0.0. Автоматическую
загрузку обеспечивает этот файл; ручной краткий статус доступен через
`/dt-status`. Это осознанная замена, не обещание прежнего экранного индикатора
или восстановления внешнего legacy-store. Приватная история сохранена отдельно.

После обрыва лид проверяет `dt recover <project>` на хосте постоянного сервера.
Возобновлять можно только точные сохранённые member, lead-session и task.
Не запускай второй сервер, не путай timeout с неисполнением, не обещай exactly-once.
Продуктовые вопросы задаёт человеку только tech-lead интерактивным question;
остальные роли передают неопределённость лиду сообщением.
